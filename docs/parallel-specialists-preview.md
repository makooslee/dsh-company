# Parallel specialists preview

Optional company plan for a bounded, text-only objective. The owner sees the precise roster, why each employee was picked, the dependencies and possible additional model use, and approves the specific revision before manually starting it.

* Wave 1 starts independent requirements (Product), technical options (Technical lead), and supplied evidence/risk (Analyst) from the same approved objective. They do not consume sibling output.
* Wave 2 integrates all three successful outputs (Engineer).
* Wave 3 independently checks the result (QA).
* Wave 4 independently reviews both the deliverable and QA evidence (Reviewer).

Missing active roles or changed approved bindings fail closed; a reported blocker halts dependent steps. Six distinct employees are required. Existing owner approval, guard, retry bounds, and worker ownership remain in force. The option is a predesigned reusable decomposition, not an arbitrary model-generated project plan. It does not browse, edit files or publish, and an orchestrated mock overlap is not evidence of real latency savings, output quality, or production performance. Legacy and saved workflows keep their behavior. Review pass may permit optional promotion through the existing company template path.
