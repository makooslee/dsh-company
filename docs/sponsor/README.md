# Sponsorship / 赞赏

主 README 和插件面板里的「赞赏」按钮读的是同一个文件：

```
docs/sponsor/wechat.png
```

## 放图

把微信收款码保存为上面的路径即可，两边同时生效：

- README 的「赞赏」一节直接内嵌这张图；
- 插件面板右上角「赞赏」按钮弹窗里显示同一张图（Host 从包目录读文件后伺服，不走外链）。

支持 `png` / `jpg` / `webp` / `gif` / `svg`；换文件名请同步改 `cordis.patch.yml` 的 `sponsorImage`。

## 关于二维码与 Git

二维码一旦提交进 Git 历史就很难彻底删除。两种做法：

1. **直接提交**：方便，但公开仓库里会永久留痕（收款码本身不含账号密码，风险可控，但会被爬虫采集）。
2. **只放本地 / 图床**：把 `docs/sponsor/wechat.png` 加进 `.gitignore`，README 里改成外链图片。

想换图的时候直接覆盖同名文件，记得顺手清缓存（浏览器会缓存 60 秒）。
