# AI 公司工作台预览（独立版本，未发布）

- **下发任务**：打开 AI 公司，顶部下发任务会聚焦输入。创建方案后默认推荐精简方案，仍需明确批准后再开始。左栏高亮正在执行步骤的成员，中央显示真实输出，右边给出审批和证据。
- **运行模板**：到固定流程，卡片上直接输入本次任务并点运行模板。不用打开编辑器。编辑用于改步骤；原历史不会传给新运行。
- **拉群**：从左栏或顶部打开群聊，点新建，选 2–6 位员工。只有点击发送才开始模型调用；群中显示每人真实回复和运行状态。不同群的会话内容分开。此版本不支持员工自己拉群、多人共享账号权限或访问项目文件。
- 历史任务/方案与群聊是两个入口，不把流程节点伪装成员工聊天。
- 平台验证：真实隔离 Harness + 本地模拟模型；测试了两成员同时回复、A/B 群隔离、重启恢复。新 UI 尚未在日常 Mac Desktop 安装或用真模型运行。
