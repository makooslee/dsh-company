# 量化作战室 · 动态事件流预览

公司 → 量化作战室。重点从“最近一次摘要”改成真正可追溯的事件窗口：

- 盘中只读模式：每五秒查询真实日志变化；新增稳定事件才亮起对应岗位并追加记录，首次加载、刷新或空源不会演示假动态。跟随关闭只影响视图，不影响读日志。
- 历史回放：在配置 replay 时点“播放真实记录”，逐条播放最近最多 80 条实际记录。暂停停止推进，重置回到开头。此动画压缩时间但保留每条原始北京时间，不是实时行情，更不执行交易。
- 左栏为职责岗位及当前证据；中心为可跟随的筛查、审核、跳过、SMTP历史受理等事件。打开快照指标看更多计数。原始报价、持仓、收件人、日志自由文本不显示。
- 行情真实性、完整日历、题材、卖出可卖数量仍要独立核验。这里不会启动交易系统、实际发送邮件或下单。持久群聊和固定流程依旧可分别使用。

本包仅独立测试，不会覆盖正常 Desktop 或 npm。配置和只读边界见《量化作战室预览：只读日志接入》。
