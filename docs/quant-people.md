# 量化作战室 · 实名员工工作台

打开「公司 → 量化作战室」。左栏按公司已聘员工列出，不用先有行情、不用先配岗位。实际有公司步骤、固定工作流、旧任务或成员群回复在执行时，展示相应来源与状态。已记录的公司步骤可显示一段上次产出；非当前记录、旧无快照、跨群的私有正文不会被猜测或硬拼。

「遥测负责人」可从在岗员工中选择，保存后由当前本地 Harness 配置持久保存。负责某个岗位不等于已经执行、审批或发信。TradingAgents 扫描、审核、SMTP 回执等仍显示在独立事件流，不冒充员工消息。删除/停用的员工不能被分配。这里只是显示与分工预览，不会创建实际交易或邮件工作。

此预览未覆盖主 Desktop，未发布 npm。
